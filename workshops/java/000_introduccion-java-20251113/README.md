## Descripción

Este es el repositorio oficial del taller introductorio a Java de la Hora del Código de 2025.

Este taller está orientado a principiantes dentro del mundo de la informática que estén interesados en aprender como primer o segundo lenguaje *Java*.

En la sesión de 2 horas que se imparte aprenderás:

- **Sintaxis básica de Java**: Variables, tipos de datos y operadores.
- **Estructuras de control**: Condicionales `if-else` y bucles `while do-while for`.
- **Funciones y procedimientos**: Reutiliza código y aprende a modular tu programa.

## Requisitos

Se recomienda a los participantes que:

- No es necesario que tengan experiencia en programación ni informática.
- Tener instalado un IDE de desarrollo (Visual Studio Code, Netbeans, Eclipse, Intellij IDEA, etc...)
- Entorno de ejecución de Java (JRE) y sus herramientas para el desarrollo (JDK 11)

## Otros detalles

Para el que quiera dar este taller, recomiendo:

- Tenga una base sólida en Java
- Haber aprobado Fundamentos de Programación (o equivalentes en otros grados)
- Tenga capacidad para explicar conceptos complejos de forma sencilla
- Sepa tratar con principiantes y grupos voluminosos.
